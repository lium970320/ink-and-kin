# 书中人 · Ink & Kin

> Where ink becomes kin.

Ink & Kin is a self-hosted app for chatting with AI characters and writing stories together. Create a character from your own settings or a PNG character card, upload excerpts or an EPUB, and connect a model of your choice. Characters can draw on the source library and memories you review. Use a separate scene for a specific story, or gather several characters in a roleplay channel.

The read-only UI preview runs on sample data. The full app uses Node.js 22.12 or newer, pnpm 10.33.3 via Corepack, and PostgreSQL. It listens on loopback with registration closed by default. A configured cloud service receives the context needed for its requests.
