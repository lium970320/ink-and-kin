- 版本：方案稿 v0.1（2026-11-16）
- 范围：全站视觉、交互与动效重构，**现有功能、接口、路由和数据合同一律不变**。

## 2. 设计理念

**一句话**：把「与书中人相识」做成一间灯下的书房——角色是书架上的书，对话像在读一页正在被写下的书，你的光标是那盏阅读灯。

三条原则，冲突时按顺序取舍：

1. **可读优先**：长文（对话、场景、日记、人物小传）按书籍排版处理：每行 34–40 个汉字，行高 1.8 以上，正文对比度至少 7:1。装饰不得压在正文上。
2. **材质而非装饰**：高级感来自克制的材质（纸页层级、布面色、0.5–1px 的烫金细线、带色相的阴影），不靠渐变、发光和大面积毛玻璃。每屏最多一个金色焦点。
3. **动效有来由**：每个动效都对应一个物理隐喻（光、墨、纸、丝带）。动效服务于反馈和空间关系，没有纯装饰的循环动画；常驻循环动画全站不超过两处（在线呼吸点、流式光标）。

视觉母题清单：

| 母题 | 用在哪里 |
|---|---|
| 书封 + 书脊 | 角色卡、场景卡、新建入口 |
| 烫金内框（inset 细线） | 角色卡、登录卡、弹窗标题区 |
| 丝带书签 | 品牌标、标签/导航的活动指示、收藏与置顶标记 |
| 章节号（壹 贰 叁） | 设置目录、欢迎页功能介绍、场景序号 |
| 纸页层级（e0–e4 阴影） | 所有卡片、浮层、弹窗 |
| 灯光 | 悬停光斑、首屏环境光、深色模式的主色 |
| 墨 | 点击扩散、内容显现、流式输出 |

## 3. 设计变量（Design Tokens）

所有数值都同时写进预览页，可在预览页「设计变量」一节实时对照。

### 3.1 色彩：靛金（推荐）

| 语义变量 | 浅色「象牙纸 · 靛墨」 | 深色「夜读 · 鎏金」 | 用途 |
|---|---|---|---|
| `--background` | `oklch(0.975 0.008 88)` | `oklch(0.175 0.024 270)` | 页面底色 |
| `--card` | `oklch(0.992 0.004 88)` | `oklch(0.212 0.026 270)` | 卡片 / 纸页 |
| `--muted` | `oklch(0.952 0.010 86)` | `oklch(0.190 0.024 270)` | 凹陷区、分段控件底 |
| `--popover` | `oklch(0.998 0.003 88)` | `oklch(0.245 0.028 270)` | 浮层、弹窗 |
| `--foreground` | `oklch(0.235 0.032 268)` | `oklch(0.925 0.014 85)` | 正文 |
| `--muted-foreground` | `oklch(0.470 0.022 268)` | `oklch(0.720 0.016 85)` | 次要文字 |
| `--primary` | `oklch(0.430 0.125 268)` 靛青 | `oklch(0.800 0.105 80)` 鎏金 | 主按钮、链接、选中 |
| `--primary-foreground` | `oklch(0.985 0.006 88)` | `oklch(0.200 0.030 270)` | 主按钮文字 |

| `--gold-ink` | `oklch(0.520 0.100 70)` | `oklch(0.830 0.100 82)` | 需要承载文字的金色（章节号、强调标签） |
| `--border` | `oklch(0.885 0.012 86)` | `oklch(0.300 0.024 270)` | 分割线、描边 |

| `--destructive` | `oklch(0.520 0.170 22)` 绛红 | `oklch(0.680 0.150 22)` | 删除、错误、丝带书签 |
| `--success` | `oklch(0.550 0.100 158)` | `oklch(0.720 0.110 158)` | 成功、在线 |
| `--warning` | `oklch(0.660 0.130 62)` | `oklch(0.800 0.120 70)` | 提醒、解析中 |

设计意图：浅色模式是「墨写在纸上」，主色为靛青；深色模式是「金字印在布面上」，主色翻转为鎏金。语义变量名不变，组件不需要知道当前是哪种模式。

对比度目标（按 OKLCH 亮度估算，实施时用工具逐项复核）：浅色正文与底色约 14:1，次要文字约 6.3:1，靛青主色约 7.5:1，`--gold-ink` 约 5.1:1；深色正文约 15:1，次要文字约 7.6:1。`--gold` 本身在浅底上对比不足，**只用于非文字装饰**。

备选「烟紫 · 茶金」：浅色主色 `oklch(0.45 0.10 340)`、底色 `oklch(0.975 0.008 60)`；深色底色 `oklch(0.18 0.022 330)`、主色茶金 `oklch(0.80 0.085 62)`。气质更柔和、偏情感陪伴，但书卷气弱于靛金。预览页右上角可切换对比。

### 3.2 情绪色与图表色

| 情绪 | 浅色 | 深色 |
|---|---|---|
| 温暖 | `oklch(0.60 0.12 50)` | `oklch(0.76 0.11 55)` |
| 俏皮 | `oklch(0.64 0.12 85)` | `oklch(0.80 0.11 88)` |
| 怀旧 | `oklch(0.55 0.10 250)` | `oklch(0.74 0.09 250)` |
| 忧郁 | `oklch(0.52 0.09 295)` | `oklch(0.72 0.08 295)` |
| 愉快 | `oklch(0.56 0.10 155)` | `oklch(0.74 0.10 155)` |

| 角色 | 字体栈 | 说明 |

中文排版规则：长文区 `max-width: 40em`（约 38 字/行）；段间距 0.75em；标点使用 `text-spacing-trim` 与 `hanging-punctuation`（浏览器支持时生效）；旁白和动作描写用宋体斜体 + 次要文字色，与对白区分。

### 3.4 圆角、间距、阴影

- 圆角：`--radius-sm 6px`、`--radius-md 10px`、`--radius-lg 14px`、`--radius-xl 20px`（仅弹窗）、`--radius-pill`。书封卡使用 `6px 12px 12px 6px`（书脊一侧更方）。
- 间距：4px 基准，常用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 72。
- 阴影（纸页层级，阴影带靛色色相，不用纯黑）：

| 层级 | 场景 | 值（浅色） |
|---|---|---|
| e0 | 平铺，只有描边 | `none` + `1px solid var(--border)` |
| e1 | 静止卡片 | 内顶高光 + `0 1px 2px ink/6%` + `0 6px 16px -10px ink/14%` |
| e2 | 悬停卡片、下拉 | `0 18px 40px -18px ink/30%` |
| e3 | 浮层、抽屉 | `0 24px 56px -20px ink/34%` |
| e4 | 弹窗 | `0 40px 100px -24px ink/45%` |

- 材质：全局叠一层纸纹。纸纹在启动时用 canvas 预先生成一张 160×160 的噪点小图并平铺（图层不透明度浅色 4.5%、深色 5%），放在固定定位的独立合成层上，滚动时不重新绘制；不使用实时 SVG 噪声或 `invert` 滤镜。**全站不使用毛玻璃**（`backdrop-filter`）：顶栏、遮罩、浮层一律用不透明或高不透明度的纯色，层次靠阴影和金色细线表达。

## 4. 动效与交互系统

### 4.1 时长与缓动

| 变量 | 值 | 用途 |
|---|---|---|
| `--dur-press` | 90ms | 按下反馈 |
| `--dur-fast` | 160ms | 颜色、描边、悬停 |
| `--dur-base` | 240ms | 开关、分段、小型状态切换 |
| `--dur-slow` | 420ms | 面板、卡片抬起、内容进入 |
| `--dur-page` | 560ms | 抽屉、主题切换、页面级过渡 |
| `--ease-out` | `cubic-bezier(.22, 1, .36, 1)` | 进入、悬停（默认） |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | 位移、指示条 |
| `--ease-emph` | `cubic-bezier(.2, 0, 0, 1)` | 抽屉、主题揭幕等大幅运动 |
| `--ease-exit` | `cubic-bezier(.4, 0, 1, 1)` | 退出（退出时长取进入的 0.6–0.7 倍） |

framer-motion 弹簧沿用现有三档，只改语义名：`SPRING_PRESS`（≈ SNAPPY）、`SPRING_LAYOUT`（≈ SILKY）、`SPRING_GENTLE`。阻尼比保持在 0.86 以上，不出现果冻式回弹。

### 4.2 招牌交互

| 名称 | 触发 | 表现 | 关键参数 | 降级 |
|---|---|---|---|---|
| 灯影 | 指针悬停在 `[data-lamp]` 元素（卡片、列表项） | 一团暖光跟随指针在卡片内移动（单层径向渐变，不做遮罩描边光） | 光斑半径 260px，灯光色混合比例浅色 42%、深色 15%，淡入 240ms；指针坐标只写在当前卡片上 | 触屏、减少动效与轻量模式：只保留静态的悬停描边变化 |
| 环境灯 | 欢迎页、大厅首屏 | 页面背景上一团极淡的大光晕缓慢跟随指针（带惯性滞后），首屏插画按层级视差 | 插值系数 0.08，视差 ≤ 12px，只用 `transform` | 关闭，光晕固定在左上 |
| 墨晕 | 点击 `[data-ink]`（按钮、卡片、菜单项） | 从按下处晕开一团柔边墨色（中心实、边缘虚），随后淡出；键盘触发从中心晕开 | 650ms `--ease-out`，透明度 0.28→0 | 关闭，只保留按压缩放 |
| 按压 | 所有可点控件 | 按下缩到 0.97，松开回弹 | 按下 90ms，松开 240ms | 保留（幅度很小） |
| 磁吸 | 仅主操作按钮与发送键 `[data-magnetic]` | 指针靠近时按钮朝指针偏移 | 水平 ≤ 6px，垂直 ≤ 4px，离开 500ms 归位 | 关闭 |
| 书签指示条 | 标签页、分段控件、顶栏导航 | 选中标记以书签丝带的形态滑到新位置，文字颜色同步过渡 | 420ms `--ease-emph` 或 `SPRING_LAYOUT` | 直接切换 |
| 点灯 / 熄灯 | 切换浅色 / 深色 | 以点击位置为圆心，新主题以圆形揭幕铺满全屏（View Transitions API） | 560ms `--ease-emph` | 不支持该 API 或减少动效：200ms 交叉淡化 |
| 墨迹显现 | 区块、列表首次进入视口 | 透明度 0→1、上移 14px→0，依序错开（不做模糊） | 640ms，每项错开 50ms，最多 8 项；动画结束后不保留填充状态 | 只做 150ms 淡入 |
| 笔尖光标 | 流式输出中 | 文本末尾一支带微光的金色笔尖闪烁，新文字按片段（非逐字）淡入 | 片段 360ms 淡入，光标 1s 闪烁 | 光标不闪烁 |
| 共享元素过渡（可选增强） | 大厅书封 → 聊天页 | 角色头像和名字从书封平滑移到聊天顶栏 | View Transitions 命名元素 | 不支持时用现有淡入 |

### 4.3 性能与可访问性约束

1. 动画只改 `transform / translate / scale / opacity`，**不对 `filter`（含模糊）做动画，不使用 `backdrop-filter`**；高度展开继续使用现有的 `collapse-grid`（`grid-template-rows` 0fr→1fr）。
2. **路由外层包裹不加 `transform / filter`**（现有约束：会形成新的包含块，破坏内部 `position: fixed`）。页面级过渡用透明度或 View Transitions。
3. 指针相关效果共用一个文档级 `pointermove` 监听（`passive`），每帧最多处理一次（`requestAnimationFrame`）；每帧先统一读取位置、再统一写入样式；元素位置只在进入时读取一次并缓存，悬停中不反复触发重排；页面滚动时立即清除灯影与磁吸、使缓存失效，滚动期间不追踪指针。
   - 指针坐标变量 `--mx / --my` 用 `@property` 注册为**不继承**（`inherits: false`），伪元素用 `--mx: inherit` 显式取值；这样指针移动时只重算当前卡片，不会让整棵子树重算样式。
   - 常驻循环动画（在线状态点、徽标脉冲、骨架屏扫光）只用 `transform / opacity` 驱动的伪元素，不对 `box-shadow`、`background-position` 做动画。悬停阴影加深用「预先画好阴影的伪元素 + 透明度过渡」，不直接过渡 `box-shadow`。
   - 视差层用 `transform: translate3d()` 并加 `will-change: transform`；流式输出区域不开平滑滚动，避免每段新文字都触发一次滚动动画。
   - **轻量模式**：设置里提供「轻量模式」开关，开启后关闭环境灯、纸纹与灯影，保留按压与过渡；另外在页面首次滚动或移动指针时采样约 120 帧，若帧间隔中位数超过 25ms，或超过 40ms 的帧占比超过 20%，自动开启并提示用户（可手动关回）。
4. 指针效果只在 `(hover: hover) and (pointer: fine)` 下启用；`prefers-reduced-motion: reduce` 时全部关闭，与现有 `MotionConfig reducedMotion="user"` 保持一致。
5. 墨晕不替代焦点样式；键盘焦点环统一为 2px `--ring` + 2px 底色间隙，进入时 `outline-offset` 由 4px 收到 2px。
6. 触控目标桌面 ≥ 36px，窄屏 ≥ 44px。
7. 性能指标：交互到下一帧绘制（INP）< 200ms；悬停与滚动在中端笔记本保持 60fps；长对话列表使用 `content-visibility: auto`。

## 7. 不覆盖原版的实施方式

### 7.1 双风格并存（推荐）

- 在 `<html>` 上增加 `data-ui` 属性：`classic`（现有界面，默认）/ `ink`（灯下书房）。与现有的 `.dark` 类正交，组合出四种状态。
- 新风格的变量和组件覆写全部写在 `:root[data-ui="ink"]` 选择器下，**经典风格渲染结果保持不变**。
- 在「设置 → 外观」增加「界面风格」选项，值保存在 `localStorage`；`index.html` 内联一段很短的脚本，在首帧绘制前设置 `data-ui`，避免闪烁。
- 交互层（灯影、墨晕、磁吸、主题揭幕）在 `main.tsx` 安装一次，运行时检查 `data-ui="ink"`，经典风格下不生效。
- 验收后把默认值改为 `ink`，经典风格保留一个版本周期再移除。

### 7.2 文件组织

```
client/src/styles/
  ink/tokens.css         颜色、字体、圆角、阴影、动效变量（浅色 / 深色 / 备选色板）
  ink/base.css           底色、纸纹、排版、滚动条、焦点环
  ink/components.css     .warm-card、.app-header、气泡、输入台等现有类的覆写
  ink/interactions.css   灯影、墨晕、磁吸、揭幕、显现的样式部分
client/src/lib/interactions/
  lamp.ts  ink-ripple.ts  magnetic.ts  theme-reveal.ts  reveal.ts
client/src/components/BrandMark.tsx
client/src/hooks/useUiStyle.ts
```

`index.css` 只追加 `@import`，原有内容不删。

### 7.3 结构差异的处理

优先「同一套 DOM + 不同样式」。必须改结构的组件（书封卡、聊天消息、设置目录、欢迎页插画）通过 `useUiStyle()` 在组件内部切换，控制在 5 处以内，并保证两种结构的 `aria` 属性和测试选择器一致。

### 7.4 版本管理

- 各阶段完成后将改动推送到 `main`，对应快照使用 Git 附注标签。默认风格如需切换，单独提交。

## 9. 风险与取舍

| 风险 | 应对 |
|---|---|
| 宋体子集体积（常用字约 1–2 MB） | 只用于标题与人名；按需加载；也可只在 `ink` 风格下加载 |
| 角色消息去气泡后，多人频道里不易分辨说话人 | 多人频道保留气泡；单聊默认书页排版，并提供开关 |
| 写死颜色替换面广，可能误伤经典风格 | P0 只做「等值替换」，以截图基线兜底 |
| View Transitions 浏览器支持不一 | 全部做特性检测，不支持时回退为淡入淡出 |
| 指针效果与大面积材质在低端设备、集成显卡或高分屏上掉帧 | 不用毛玻璃和滤镜动画；纸纹用预生成位图；统一监听 + 每帧一次 + 先读后写 + 只改 `transform / opacity`；设置里提供「减少动效」（跟随系统并可手动覆盖）与「轻量模式」（帧率偏低时自动开启） |
| 金色在浅色底上可读性差 | `--gold` 仅作装饰，文字统一用 `--gold-ink` |
