# 安卓手机直连

书中人直连让同一局域网内的安卓手机使用现有书中人账号。手机和网页可以使用同一批角色，查看各自有权访问的对话和场景。手机支持文字、录音、图片和实时回复。录音转文字与图片理解分别使用该账号配置的转写服务与视觉模型。

## 启用服务器

在源码或服务端部署中，先更新数据库，再修改服务器的 `.env` 并重启。

```sh
corepack pnpm db:migrate
```

```dotenv
APP_MOBILE_ENABLED=true
APP_HOST=0.0.0.0
```

`APP_HOST` 也可设为服务器在可信局域网内的具体 IPv4 地址。手机访问服务器的 HTTP 端口，自动查找另外使用 UDP 30003。可在发现失败时手动输入地址。Docker 默认仅将 HTTP 端口映射到宿主机回环地址。通过容器提供局域网服务时，部署者需要为受信任的网卡显式配置端口映射。 [服务器访问与隐私](../SECURITY.md#服务器访问)

## 安装与配对

1. 从本仓库 Actions 的 **Android** 已通过构建下载调试安装包，或按 Android 源码说明自行构建。要让网页设置提供安装包下载，把 APK 放进部署者的运行目录，并将 `APP_MOBILE_APK_PATH` 指向该文件。
2. 将手机和服务器连入同一可互访的局域网。登录网页，打开**用户中心 → 手机直连**，选择手机可达的服务器地址，生成六位配对码。
3. 在书中人直连中选择自动发现的服务器，也可手工输入地址。输入配对码或用相机扫配对二维码，确认屏幕上是自己的服务器。配对码有效期为三分钟，兑换成功即失效。
4. 在手机上打开一个已就绪的角色。部署者可从网页查看设备的在线状态和上次活动时间。账号所有者可随时在设置中撤销设备。

调试 APK 适合自测。长期分发时，构建者需要为同一个应用 ID 保管自己的签名密钥并使用一致的正式签名。 [Android 构建](../android/README.md) · [Android CI](https://github.com/lium970320/ink-and-kin/actions/workflows/android.yml)

## 在书中人和 Mirrai 之间切换

书中人直连 1.1.0 支持现有的 Mirrai 1.x 服务。分别配对两台服务器后，从手机 **设置 → 已保存的服务器** 切换。客户端分别保存会话，手机可在能到达对应服务器的网络下复用已登录账号。 [安卓客户端说明](../android/README.md)


## 投递与数据

主动消息仍由网页端角色的主动计划触发。账号可选择手机优先、QQ 优先、同时投递、仅手机或仅 QQ。QQ 路径需要该角色事先获得明确授权。手机实时提醒需要已配对的客户端在线，站内保存的消息可在网页主动消息收件箱查看。

设备可以通过设置页单独撤销。服务器保存设备令牌的哈希和必要的设备信息，随应用数据一起备份。设备只能用令牌访问自己的内容。启用手机直连的明文 HTTP 适用于可信局域网，跨不可信网络时需要由部署者使用 HTTPS 和 WSS。Android 后台实时提醒受系统的前台服务和省电限制。 [安全与隐私](../SECURITY.md)
